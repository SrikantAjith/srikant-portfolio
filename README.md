# Srikant Ajith — Developer Portfolio

Responsive React + Vite portfolio with a dark editorial design inspired by the reference site, implemented as original code.

## Run locally
Requires Node.js 18+ and npm.

```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import it in Vercel using **Add New → Project**.
3. Build command: `npm run build`; output directory: `dist`.
4. Deploy.

## Before publishing
- Replace the LinkedIn URL in `src/main.jsx` with your actual profile.
- Confirm the transaction figure, reporting period, and scope.
- The updated resume is included as `public/resume.pdf` if available.
- Verify repository URLs and contact details. Do not publish employer/customer confidential information.

Stack: React, Vite, CSS, Lucide icons.
